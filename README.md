# SigapKlaim

Prototype klaim asuransi digital (Smart Insurance Claim & Data System).
Tugas Kelompok 1 Entrepreneurship, BINUS Online, Week 7 Sesi 11.

Scan barcode polis, foto KTP terbaca otomatis, foto kerusakan, tanda tangan digital, dan pelacakan status klaim. Semua data di prototype ini **fiktif**.

## Coba

Buka halaman demo, lalu tekan **Putar demo otomatis** atau coba sendiri lewat HP.

## Catatan

Prototype ini hanya simulasi tampilan dan alur (mid-fidelity), belum terhubung ke database atau sistem asli. Angka "± 1 hari" adalah estimasi target, bukan hasil terbukti.
